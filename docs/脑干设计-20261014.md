## 0. 为什么需要脑干

现有三器官回答了"思考 / 记忆 / 在场"，但**缺一个让它"活着"的层**：**常驻、皮层无关、在两次思考之间也不熄灭**。——否则仍是"请求-响应"的工具，不是有机体。

## 1. 生理脑干 → AI 类比（草案）

| 生理功能 | AI 对应 |
|---|---|
| 呼吸 / 心跳（自主节律） | **心跳回路**：常驻调度器，周期性唤醒系统（= 能动的引擎） |
| 网状激活系统 RAS（唤醒 / 警觉） | **唤醒门控**：何时把皮层拉起思考、何时待机 |
| 睡眠 / 觉醒周期 | **睡醒循环**：醒→工作，睡→**M2 巩固 / dreaming**（睡眠本就由脑干驱动） |
| 稳态（体温 / 血糖） | **homeostasis**：资源 / 健康 / 记忆压力 + **三道关护栏**（本我/自我 = 系统属性） |
| 反射（无需皮层） | **反射**：快速非-cortex 响应（危险动作遏制 = 超我护栏一半） |
| 脑干 = 桥接中枢 | **常驻总线**：连接 cortex ↔ 器官 ↔ VEGA |

## 2. 三条关键作用

1. **连续性的真载体**：会话间隙系统不熄灭 ⇒ **M0 的物理底座**。
2. **§9.2「授权 / 能动」的执行者**：心跳回路驱动 ⇒ "谁在让模型主动"有了答案（授权 = 允许；脑干 = 执行）。
3. **M2 睡眠巩固的驱动者**：睡醒周期由脑干控 ⇒ dreaming / 巩固挂在它的**睡眠阶段**。

## 3. 落在哪（拓扑，草案）

- **常驻编排层**，与"接线层(gateway) / 器官(Hippocampus)"同居或相邻。
- 倾向放 **appliance 侧（Hippocampus 同机）**——保证"器官常驻、不随皮层起落"。

## 4. 与既有设计的关系

- 三道关护栏（本我 / 自我 = 系统属性）→ 脑干的 **homeostasis（稳态）** 职能。
- 反射 / 超我（危险动作遏制）→ VEGA S4 + 脑干**反射**。
- 授权记忆（§9.2）→ 脑干**每次唤醒时注入**。

> 来源：2026-10-14 会话「脑干设计评审」。性质 = 设计推演/评审结论。带 ⚠️ 者曾与现行章程不一致——**2026-10-14 经用户「确认」已采纳，同步入章程 §10**；未带 ⚠️ 的 6.5 / 6.6 仍作设计参考。

### 6.1 定位再确认（为何此器官最"实"）

三器官（思考 / 记忆 / 在场）全为**被动反应式**，**无人回答「谁决定何时巩固」「两次思考之间系统是否活着」**。脑干填的正是这个洞：

- **M2 巩固的驱动者**：S1「深夜复盘」= 生物学的**睡眠期海马回放 → 新皮层巩固**，教科书级对应。无它，M2 只能手动 / 客户端触发，"自己会做梦"长不出来。
- **M0 的物理底座**：会话间隙不熄灭 = "有机体" 与 "请求-响应工具" 的分水岭。

### 6.2 ✅ 硬不变量：脑干永不"变聪明"（2026-10-14 已确认）

「只发信号、不判断」须从"非目标"**升格为架构不变量**。章程 §3 的 S2/S3 措辞（"启动 LLM 搜索""检查健康"）已在**危险边缘**——一旦试图加入"值不值得做"的判断，脑干即长成**第二皮层 / 第二个 agent**，破坏三件事：①单一自我（"我住在记忆里、不在模型里"）②皮层可换 ③模块化接口（章程 §9）。

**铁律**：脑干 = 纯机械信号源；一切价值判断归消费者（器官门控 / 皮层）。

### 6.3 ✅ 补齐本职：生命维持 / 反射（2026-10-14 已确认）

真脑干 = **自主生命功能 + 保护性反射**；现行 v1 只有"定时 + 空闲" = **纯调度器**，漏掉最脑干的东西：

| 生理本职 | AI 对应 | 现状 |
|---|---|---|
| 心跳 / 呼吸（自主生命维持） | **liveness / watchdog / heartbeat**：网关 / 器官挂了谁发现、谁拉起 | ❌ 无主（现散落 `gb10-tf-memguard` 等） |
| 反射（无需皮层） | **快速非-cortex 响应**（危险动作遏制等） | ❌ v1 未纳入 |

**建议**：把 `路线与判据.md` §4「三道关」中的**系统属性护栏**（本我 = 持久 / 备份；自我 = 连贯 / 健康检查）**落为脑干职责**——它是稳态 / 自主器官，这是最干净的归属，也让脑干超出"计时器"。

### 6.4 ✅ 与网关边界：两个"接线层"须定死（2026-10-14 已确认）

网关（接线层）与脑干（信号 → 消费者接线）**都是接线，易重叠**。须显式定 **信号总线契约（发布 / 订阅）**，并硬性规定 **脑干 = 纯发布者**、永不 import 网关 / 器官内部（坐实章程 §9）。

### 6.5 理论轴卫生：脑干属「器官（解剖）轴」

脑干属**解剖轴**（皮层 / 海马体 / 脑干 / VEGA），**不得**与弗洛伊德精神轴（本我 / 自我 / 超我）或荣格轴（Persona / Self）并列。本文 §4「反射 / 超我 → 脑干反射」应改述为**「某器官实现某功能」**（如"脑干以反射实现危险动作遏制这一功能"），避免概念混轴。

### 6.6 研究价值（可选，指向北极星）

脑干 + **睡眠式自主巩固** = 多数记忆 agent 论文没有的维度（常见系统全为 reactive：查到才回忆）。"无人提问时系统对自己做事" = 真主动性，且**可消融**（reactive-only vs +自主睡眠巩固）。与"换皮层一致性"并列为潜在研究的两条腿。
