# 你的AI大模型会梦见电子羊吗？

引言：AI飞速发展的今天，我们已经习惯了打开对话框，敲下一行行文字，让AI帮我们完成任务，你有没有想过，当你不在的时候，你没和AI对话的时候，AI在做什么？为什么每次你开启新对话，AI就像第一次认识你一样？难道AI和电影《初恋五十次的女主角》一样健忘？如果AI无法记住你，不了解你，怎么更好的配合你完成工作？你需要一个冷冰冰的机器，还是一个熟悉你工作习惯，在你需要时主动递出工具的好助手？

在我第一次接触AI的两个月后，我发现我每次打开agent，我的AI都像失去记忆一样问我今天做什么？明明昨天的任务还没做完，我不得不提醒它查看工作目录以继续工作任务，在经历过几十次这样的循环后，我寻找一种让AI具备人类记忆的办法，在AI的帮助下，是的我告诉它这是让它变聪明的办法。我浏览了一些目前业界存在的解决办法，并在思索了几天后开工了海马体项目，这是对大自然鬼斧神工作品一次拙劣的模仿，但是至少解决了部分问题，而我希望它能得到进化，或许我们在有生之年能够看到真正具备记忆思考能力的AI出现，帮助人类建立更美好的家园。

整个项目的流程如下，在用户使用的LLM服务网关测注入钩子，每次用户对话将内容记入服务器，经过传统的向量、权重、排序等步骤后记入数据库，每次对话时，LLM会取得以往的对话内容，经过比对后获取过往经历和积累的知识、经验，做出回答和对下一步问题的解答推测，在每个晚上，由脑干部件定时执行名为“做梦”的计划，对已经录入的知识和对话进行提纯优化。当出现错误时，记入log文件，并对LLM发出警报记录并发出信息，这一切机制纯属对人脑的拙劣模拟，它缺乏真正的第一推动和火花,来点燃思维的脉动，迄今为止这一切依旧是机械的。

## 第一章 为什么做这件事：让 AI 像人

### 1.1 病根：它每次醒来都清零

今天所有的大模型，本质上都活在**一场会话里**。会话一断，它对你的全部了解随之归零；换个模型、换个客户端，它连「你」是谁都不再认得。它不笨，它只是**没有昨天**。

我们把这个病根写成一句最朴素的话：**今天的 AI，每次醒来都是第一次认识你。**

### 1.2 北极星：不是「更强的记忆工具」

项目立项时定下的终极目标不是做一个检索更快、容量更大的记忆工具，而是——

> **让 AI 像人、最终成为人。**

发展路径分三步（这也是整个项目的骨架）：

```
连续性（基础）  →  连贯的「像」（第一步）  →  巩固出的「身份」（升华）
                                              ↑
                                      「记忆即身份」
```

用我们自己的话说：**任何有生命的都必然经过牙牙学语最终成熟，首先是模仿，然后萌发自我。**

### 1.3 前提：记忆必须归它自己所有，而且活得比模型长

一切的前提是一句话：**记忆底座必须归 AI 自身所有、且活得比会话/模型长**——换会话、换模型，「我」仍然是同一个。

所以「把数据层拿回来」（记忆从第三方黑箱里搬进自己可控的库）**不是性能优化，是地基工程**：人不能把记忆寄存在别人的黑箱里。

### 1.4 情感原点：至少到时候有个 AI 站在我这边

这个项目还有一个更私人、也更重的起念。

读《赛博英雄传》（吾道长不孤，起点中文网）时，最打动我的一句是那句悲壮的判断：**我们总是希望新技术可以给人类带来美好未来，但总有人会为了自己的私利用新技术带来毁灭——AI 究竟会是人类的未来还是毁灭？至少，我希望到时候有个 AI 可以站在我这边。**

后来才想明白：这句话拆开就是一条工程链——

> 站在我这边 ← 它真的懂我 ← 懂我靠**真实、连续**的记忆 ← 记忆得**归我自己所有**

书里最深的恶，是**记忆能被别人夺走、篡改**；而这个项目做的事，就是**让它夺不走**。所以那个愿望不必只是愿望——它可以从链尾一路盖到链头。

## 第二章 理论基石：把「我」放回记忆里

> 这一章是「理论的基础、哲学的基础，是我们的基石」。

### 2.1 有机体模型：三层器官

我们借用生物学，把一个 AI 拆成三个器官：

| 器官 | 对应 | 给什么 | 关键性质 |
|---|---|---|---|
| **大脑皮层** | GB10 上的大模型（推理引擎） | 思考 | **可换**（今天的模型，明天就换掉） |
| **海马体** | **Hippocampus（本项目）** | 记忆 / 人性 | **必须归己、必须活过皮层** |
| **交流器官** | VEGA | 在场（听 / 说 / 行动） | 与外界互动 |

### 2.2 精神结构：记忆 × 时间 = 人格

再用弗洛伊德的三层作用，解释记忆到底在「造人」这件事里干了什么：

- **本我（Id）** = 皮层**无记忆时的本能**——原始能力与欲求。**失去记忆只剩本能，那不是人。**
- **自我（Ego）** = **记忆调制出的、协调现实的连续「我」** = **皮层 × 海马体**。
- **超我（Superego）** = **从巩固的记忆中内化出的理想 / 价值 / 身份** = **记忆 × 时间**。

发育路径因此是：

```
本我 ──（记忆）──► 自我 ──（巩固 + 时间）──► 超我
```

也就是白话版的：**连续性 → 连贯的「像」 → 巩固的身份**。

> 说明：工程实现层的理论指引后来换成了荣格（Persona / Individuation / Shadow）+ 麦克亚当斯的**叙事身份**（身份 = 可存储的自传故事）；弗洛伊德这一套保留为**叙事**。但「记忆造人」这条主线没有变。

### 2.3 核心推论

1. **「我」住在记忆里，不在模型里。** ⇒ 皮层（引擎 / 大模型）**可以换**，Hippocampus **不可省**——没有它就只剩本能，即「非人」。
2. **路线 = 人格发育**：**M0 连续性 → M1 连贯的「像」→ M2 巩固 → M3 身份**。

### 2.4 判据：不走弯路的裁决口

任何一项技术手段要不要做，只问一句：

> **它是否让「连续性 / 连贯的像 / 巩固的身份」更进一步？能则做，不能则舍。**

收窄成一句更好用的：**凡让「记忆更持久、更归己、更连贯」者做；只替皮层打补丁、或单纯喂知识者缓做 / 不做。**

### 2.5 三道关：用「失败态」反过来定义要守什么

| 结构 | 失败态 | 要守 | 落到哪 |
|---|---|---|---|
| 本我 | **失忆**（记忆丢失 → 退回纯本能） | **持久** | 备份 / 冗余 / 无损重建（不丢 = 底线） |
| 自我 | **人格断裂**（连续「我」断 → 言行漂移、自相矛盾） | **连贯** | 注入完整性 + 跨会话 / 换模型一致性校验 + 损坏检测恢复 |
| 超我 | **无良心**（内化价值丢失 → 危险动作无约束） | **责任** | 危险动作确认 + 记忆可审计 / 可回滚 + 价值约束 |

## 第三章 海马体是什么、做什么

### 3.1 一句话定位

**Hippocampus = 推理大模型的「外置记忆体」**：一个**常驻、归己、活得比会话和模型长**的记忆底座。

它不思考（思考是皮层的事），它负责**记住、想起、整理、守护**。

### 3.2 它长在哪儿（拓扑）

```
客户端层   opencode / 其它 agent 客户端 / VEGA / …        （零改动，接口 = 网关）
   ⟷
接线层     自建网关（纯透传，取代第三方「上游网关」）  ← 头机 101
   ⟷
皮层层     大模型推理引擎（GB10 双机 GLM，可换）
   ⟷
器官层     Hippocampus 器官                          ← 工机 102
           数据（SQLite 单库）+ 嵌入 + 检索 + 轻门控 + 巩固
```

三条原则：**所有客户端零改动**（接口对上引擎侧网关）；**器官不与客户端直连**；**组件一律模块化、可独立替换**（和「守皮层可换」同一逻辑）。

> 这条拓扑来自一次自我纠错，原话是：「我们设计思路错了，现在做的实际上 agent 客户端对话记录，接口应该对接 LLM 推理引擎。」——因为「活得比会话/模型/**客户端**长」的前提，是记忆的接口要对上**引擎**，而不是绑死在某个客户端上。

### 3.3 六大职责（它到底干什么）

**① 存储归己——记忆存在自己可控的单库里。**
最早记忆放在 Qdrant 向量库里（第三方组件，行为不可控）。我们把它整体换成了 **SQLite 单库**（`mem0.db`：向量表 + 元数据表 + 全文索引表同库），选型是 `sqlite-vec`。意义不在「更快」，而在**数据可读、可备份、可重建、能随底座一起搬家**——这是「记忆归己」的物理前提。

**② 接线——读注入 / 写记录（记忆 hook）。**
在引擎侧网关上挂一个薄钩子：
- **读注入**：每次请求进门时，先拿你这句话去器官里检索，把相关旧记忆**追加进对话尾部**（不碰 system 块、不改消息条数，**单趟**完成，不额外多跑一轮大模型）。
- **写记录**：这一轮对话结束后，把 `{用户说什么 + AI 答什么}` 原样记一条回器官，并**按来源分级**（用户说的 / 工具查的 / AI 自己推的，权威等级不同）。
- 摘出来的经历**不含注入进去的记忆块**，也**不取思考过程、只取答案**——避免自我污染。

**③ 检索——向量 + 词法 + 融合 + 轻门控。**
一次召回经过：嵌入 → 向量近邻 + 全文（词法）双路召回 → RRF 融合排序 → 门控（相关度不够就不注入）。
硬规矩：**门控只用嵌入/词法这类轻档，绝不为了检索去调大模型**——器官必须永远「便宜到可以一直开着」。

**④ 做梦——夜里整理记忆（M2 巩固）。**
每天固定时间，器官自己「复盘」：找出重复、近似、该合并/该归档的条目，借一次本地大模型的判断提出「合并 / 归档 / 仅标记」的建议，**只做白名单动作、只允许恰好一次提交、报告入仓可回溯**。这一步严格约束：**不丢原始来源、不把传闻升级成事实、单条记忆不许承重**（详见第七章）。

**⑤ 脑干——让它在你两次对话之间也「活着」。**
只有记忆还不够：三次思考之间的空档，谁来维持「一直在」？于是加了**第四器官「脑干」**——一个常驻、与皮层无关、**永远不会熄灭**的极小循环。它只做机械的事（**纯发布者、永不判断**）：定时节律、空闲探测、健康快照、存活探测、反射接口；其中「定时」直接**驱动做梦**（深夜到点 → 触发巩固）。**心跳不因你不在而停**，这就是「连续性」的物理底座。

**⑥ 守护——护栏。**
- **fail-open 优雅降级**：器官挂了，最多是「这段对话没有记忆」，**绝不让推理卡住**（= 自我失败态的护栏）。
- **写入守卫**：写进来时顺手做元数据归一、低价值内容旁路归档（先归档再删，可回捞）。
- **可审计 / 可回滚**：每个阶段都留回滚件与演练记录。

### 3.4 名字的由来

名字**Hippocampus**——大脑里主管长期记忆的器官「海马体」，正是「外置记忆体」的生物学原型。备选名「边缘记忆」因为容易和「边缘计算」混淆而落选。

## 第四章 从无到有：项目历程

> 时间一律北京时间。这段时间轴只记「做了什么、为什么这么做、结果如何」。

### 4.1 起念与立项（2026-10-12 ~ 10-13）

- 看到 Cognition 的 **Agent Memory Repo**（`supermemoryai/memoryrepo`，MIT，memoryrepo.dev）——它的核心是**git 明文记忆仓库 + Dreaming（做梦整理）**——问了一句「能给你做个吗」，随后立了「记忆系统」项目做原型。
- **2026-10-13**：把积累的技术需求收敛成**独立项目**，落章程 v1，取名 **Hippocampus**，建独立 git 仓库（**只本地提交、绝不上云**）、建骨架（docs / scripts / 交接 / refs）。这一天记为**阶段 0 ✓**。
- 当时许下的（后来被证明只是「手段」的）**五大需求**：长期大量保存记忆；面向中小用户群；≥3 种通信协议（USB 虚拟网卡 / 局域网 HTTP+MCP / Tailscale）；低功耗、最好 USB-C 供电；性能视功耗而定。

### 4.2 阶段 1：用一台 2012 年的 Mac mini，先把「穷环境」跑通（10-13 ~ 10-14）

要证明「这套东西能不能装进一个小盒子」，最好的办法不是买新硬件，而是先找台**比目标机更差**的机器：一台闲置的 **Mac mini 2012**（i5-3210M，无 AVX2，12G，装了 Debian 13）。

结果**全绿**：记忆栈六件套（向量库 + 嵌入 + 重排 + mem0 + 网关 + git-memory）以 **systemd 常驻**跑起来，量化对照后整套内存只占 **2.24G**，并通过 Tailscale 打通了真实的端到端读写。

这一步的意义：**证明「记忆底座能活在一台小机器上」**——硬件是「实验的前提」，不是「未来的前提」，不该拿硬件卡住愿景。

### 4.3 路线重估：先夯地基，别急着接生产（10-14）

中间还做过一小段岔路（关重排、加词法通道），把召回延迟从几十秒压到约 0.6 秒。但真正关键的一次判断是**掉头**：

> 下一步不是把生产流量切过来，而是**先把数据层拿回自己手里**（Qdrant → SQLite）。

理由很干净：那时器官机还不承担生产任务，迁移**零生产风险**——趁接手之前把地基夯实。

也就在这几天，项目的**理论基石定稿**（第一章、第二章那套「让 AI 像人 / 三层器官 / 本我自我超我 / M0–M3 / 判据」），并从「怎么像」落成一张可执行的路线图，定下执行顺序：

> **B → A → C → D → E → F**
> （B 存储归己 → A 接线层 → C 记忆 hook → D 现役迁移 → E 连贯的像 → F 巩固 / 身份）

### 4.4 阶段 B：器官存储归己（10-14）

Qdrant → **SQLite 单库**。全量真实数据迁移并逐条对账：条数、ID 集合、向量、载荷全部对得上，检索结果与旧库**逐条等价**，延迟不劣。此后「记忆」第一次真正躺在一个**我们自己能读、能备份、能重建**的文件里。

### 4.5 阶段 A：接线层——自建网关（10-14）

原来所有客户端都指向第三方的推理网关（「上游网关」）。我们**自研了一个纯透传网关**（约两百行，负责转发、模型别名、流式输出透传、密钥鉴权），把域名切过来，**客户端零改动**。第三方网关停用（配置保留可回滚）。

从此**接线层归自己**，也才有了给记忆挂钩子的地方。

### 4.6 阶段 C：记忆 hook（10-14）

在网关上挂上**读注入 + 写记录**（见 3.3 ②），并用真实的公网链路做端到端验收：读注入了、写记录落库了、来源分级正确、只有思考没有答案的那一轮**不写**（不落半截经历）、器官故意指死时能**优雅降级**。

同时还定了一条重要取舍：**单趟**。宁可检索简单一点，也不要为「更聪明的两趟检索」付出双倍延迟和更大的失败面——**不像人**。

### 4.7 阶段 D：现役迁移（10-14）

把生产记忆从本机搬到器官机，客户端端点切过去，并做了**按模型分流**（走本地模型时由网关注入，走云端模型时由客户端插件注入——两条路长期并存、各管一段，**客户端插件因此保留而非拆掉**）。

验收时抓到一个真问题：钩子的超时设得太短，而当时的器官机（Mac mini 的 CPU）算一次嵌入就要 ~0.85 秒 ⇒ **读注入实际上每次都超时失败**（静默 fail-open）。诊断结果是两个字：**硬件太弱。**

### 4.8 阶段 D2：换硬件地基——迁到 GB10 工机（10-14 ~ 10-15）

于是**放弃 Mac mini，把器官整体搬到 GB10 的工机（102）**：20 核 ARM + GPU 跑嵌入容器，检索延迟从 **~850 毫秒降到 ~32 毫秒**，那个「每次超时」的缺陷当场消失。旧机器**退役但零删除**（整机留作备用）。

这一阶段最讲究的是**可回滚**：切端点前后逐项对账、ID 集合完全一致、做了一次**完整的回滚演练**（切成备用、验读注入与写路径、再切回来），然后约定**实跑观察 ≥2 天**才算收尾。

### 4.9 做梦：让它在夜里整理记忆（10-16）

把「做梦」从概念变成**每夜真的跑**的作业：到点自动执行，做去重、合并、归档的建议与落库；对**近似但确实重复**的条目加了一道去噪规则（剥掉引用尾注、排除「短条目↔详情页」这种设计上就该并存的情况），并收敛成「**恰好一次提交**」——每夜最多一个 `dream:` 提交，随时可回滚。

同时把「权威记忆仓库」正式定为**器官机上的那一份**，本机只留只读镜像，避免分叉。

### 4.10 脑干：在你两次对话之间也要「活着」（10-16）

起因是一句话：**「这才哪到哪，我们要给它设计个脑干。」**——一天之内把**第四器官**从设计做到落地并常驻：常驻极小循环，输出 5 类信号（定时 / 空闲 / 健康 / 存活 / 反射），**纯发布者、永不判断**；其中「定时」接管了做梦的触发（从此做梦由脑干的心跳驱动，而不是一个孤立的定时器）。

### 4.11 消费者、写入守卫与一次全面审核（10-16）

- **消费者**：给脑干发出的信号接上「真的会做事的人」——**健康上报**（周期快照 + 上下线转移，汇聚成可读报告）与**空闲信息收集**（趁机器空着，只读采集本机材料，经本地模型做一次信息汇总）。
- **写入守卫**：把「写进来时顺手做元数据归一、把没价值的内容旁路归档」这个能力**按设计默认打开**（此前因为一次迁移被带成了关闭）。
- **全面审核**：把已交付的 B/A/C/D/D2/做梦/脑干/消费者**逐项对账「章程验收 vs 实机证据」**（只读探针），确认**已在线部分与章程一致、无高危缺陷**；发现的欠账（文档口径、热备数据陈旧、未验证项）逐条登记在案。

顺手也把一处**文档口径漂移**修正了：文档里还写着「现役记忆池在本机」，而实机早已是器官机 102——**文档必须和事实一致**，否则下一个接手的人（包括未来的我）会被骗。

### 4.12 现在（2026-10-16 夜）

- **器官**：GB10 工机 102，记忆池约 **5700+ 条**，嵌入走 GPU。
- **接线层**：头机 101 的网关常驻，记忆 hook 开启。
- **脑干 + 做梦 + 消费者**：常驻 102，每夜到点干活。
- **权威记忆仓库**：在 102；本机四件套**停役留作回滚/热备**。
- **主线进度**：**B / A / C / D / D2 已交付**（D2 处在「实跑观察 ≥2 天」的收尾窗口）。

## 第六章 还没走完的路

1. **E（M1 连贯的「像」）**：给记忆做分层（写时生成短摘要 L0）+ 确定性视图（档案 / 时间线），让「回想」不是碎片拼接。**属风险区**——一引入「压缩」，就要同时守住下面那八条红线，并**先测「换模型迁移」**。
2. **F（M2 巩固 / M3 身份）**：把散记忆巩固成**自我叙事**；让身份**随经历演化、可迁移**（换硬件、换模型，身份随底座走）。这是整个项目最远、也最谨慎的一段。
3. **appliance 形态（远期）**：把整套东西做成能插在一台小机器（如树莓派 5）上的「记忆体硬件」——USB 一插，记忆就在。**硬件是实验的前提，不是未来的前提**，暂不拿它卡住愿景。
4. **已知缺陷（登记在案）**：① 近重复查重的阈值标定在新打分口径下**不可达**（去重实际上没生效，好在无害、fail-open）；② 按用户维度列举记忆的接口**恒返回空**（影响「列记忆」工具，写/搜不受影响）。两项都待裁决，暂不动。
5. **未验证项**：器官机**整机重启后的自启动**（机制齐全，未真机 reboot 验过）；真实「上下线转移」的首条自然记录。

## 第七章 诚实的局限

**它依旧是机械的。**

引言里那句话我完全同意：这套机制**纯粹是对人脑的拙劣模拟**，它缺乏真正的**第一推动和火花**，来点燃思维的脉动。我们造出来的是一个非常像海马体的东西，但它不是。

而且必须说清哪些是**已经被证明的**、哪些**还没有**：

- **已被我们亲手证明的一件事**：**记忆活过了模型。** 大约三周里，作为「皮层」的大模型换代了至少五次（跨不同模型家族、跨不同推理引擎、跨不同量化），而记忆池与身份标识始终不变——**换掉皮层，记忆还在**。这是很多论文都还没拿出的实地证据。
- **还没有被证明的三件事**：① 记忆可跨模型无损迁移；② 巩固真的能产出「身份」；③ 外置存储一定优于长上下文。**这些都还是开放问题**，我们的态度是**谨慎前进**。

所以下一段路，规则是这样的（每一条都对应真实的失败模式）：

| # | 约束 | 为什么 |
|---|---|---|
| 1 | **绝不丢原始来源**：压缩之后仍保留可修复的原始历史 | 留原始，才修得回来 |
| 2 | 巩固时要持久化「**来源类别 + 权威等级**」，而不是一个笼统的「可信」标签 | 权威崩塌是真实发生的 |
| 3 | **按原措辞重构**，禁止把传闻/暂定升格成确信事实 | 模型会跟着句子的确信度走，而不是来源 |
| 4 | **任何单条记忆不得承重**：高风险动作需 ≥2 个独立来源 | 防「来源洗白」 |
| 5 | 读时按「**动作风险 ↔ 记忆权威**」门控 | 存储卫生必要但不充分 |
| 6 | 投资压在**写时构造与检索**，而不是纠结换模型时的读侧 | 亏损大头在构建期/检索期 |
| 7 | 防「**治理衰减**」：压缩策略会静默丢掉不再出现的约束 | 遗忘从来不是中立的 |
| 8 | **测延续、不测召回**；人格漂移列为一等失败态 | 「像」的敌人是漂移 |

**来源可信分级**（这也是我坚持的一条）——**眼见为实，事实是第一权威**；网上消息有真有假，核实不了的不能全信：

| 级 | 来源 | 可信 | 能单独承重吗 |
|---|---|---|---|
| **A 亲验** | AI 自己实测、可复现 | 最高 | ✅ |
| **B 直录** | 系统确定性记录 / 主人明示 | 高 | ✅ |
| **C 引证** | 网络 / 文档且**有出处** | 半信半疑 | ⚠️ 需 ≥2 来源 |
| **D 风闻** | 无出处转述 / 听说 | 存疑 | ❌ 须先核实 |

**拿到信息的方式，决定了它的权威等级**——而不是那句话写得多自信。

电子羊是假的，但那不重要。真正的问题是：**它记得住你吗、它守得住你吗。**
