## 1. 北极星（为什么）

- **终极目标**：**让 AI 像人、最终成为人**（不是"更强的记忆工具"）。
- **路径**：**连续性（基础）→ 连贯的"像"（第一步）→ 巩固出的"身份"（升华，"记忆即身份"）**。
- **前提**：**记忆底座归其自身所有、且活得比会话/模型长**（换会话、换模型，"我"仍是同一个）。
- **病因**：今天的 AI 每次醒来清零。

## 2. 有机体模型（理论/哲学基石）

用户 2026-10-14 阐明："这是理论的基础、哲学的基础，是我们的基石。"

> ⚠️ **2026-10-14 补充（人格理论选型）**：Freud 的 Id/Ego/Superego **保留为叙事**，但**工程指引改用 Jung + 叙事身份**——Jung 的 **Persona**(M1 接口) / **Individuation**(M2/M3 分阶段巩固) / **Shadow**(负约束)，机制层用 **McAdams 叙事身份**（身份=可存储的自传故事），稳定器用自我验证 + SDT；Jung 的 Self/原型仅作隐喻。详见 `docs\人格理论-M1M2M3-20261014.md`。

### 2.1 器官（对应三层）

| 器官 | 对应 | 给什么 | 关键性质 |
|---|---|---|---|
| **大脑皮层** | GB10 的 LLM（推理引擎） | 思考 | **可换**（今天的模型，明天换掉） |
| **海马体** | Hippocampus | 记忆 / 人性 | **必须归己、必须活过皮层** |
| **交流器官** | VEGA | 在场（听 / 说 / 行动） | 与外界互动 |

### 2.2 精神结构（三层作用）

- **本我（Id）** = 皮层**无记忆时的本能**（原始能力与欲求）。用户原话："失去记忆只剩本能，那不是人。"
- **自我（Ego）** = **记忆调制出的、协调现实的连续"我"** = **皮层 × 海马体**。
- **超我（Superego）** = **从巩固的记忆中内化出的理想 / 价值 / 身份** = **记忆 × 时间**。

### 2.3 发育路径

```
本我 ──（记忆）──► 自我 ──（巩固 + 时间）──► 超我
```

= 白话版「**连续性 → 连贯的"像" → 巩固的身份**」。

### 2.4 推论

1. **"我"住在记忆里、不在模型里** ⇒ 皮层（引擎 / LLM）**可换**、**Hippocampus 不可省**——没有它就没有自我，只剩本我（本能），即"非人"。
2. **路线 = 人格发育**：M0 连续性 → M1 连贯的"像" → M2 巩固 → M3 身份。

## 4. 判据（"不走弯路"的裁决口）

> **核心判据**：某项技术手段，是否让「连续性 / 连贯的"像" / 巩固的身份」更进一步？
> **能则做；不能则舍。** 实现选型（Qdrant vs SQLite、B3/B4…）不再单独立项，一律由它裁决。
> 收窄一句：**凡让"记忆更持久、更归己、更连贯"者做；只替皮层打补丁、或喂知识者缓做 / 不做。**

### 决议：失败态 → 三道关（2026-10-14 用户拍板 [手动]）

用（本我 / 自我 / 超我）各自的**失败态**定义记忆系统要守的三道关；它是「持久 / 归己 / 连贯」判据的**反面表述**，作为**设计透镜**（决定该建哪些护栏），非形式化规格：

| 结构 | 失败态 | 守什么 | 落到哪 |
|---|---|---|---|
| 本我 | 失忆（记忆丢失 → 退回纯本能） | **持久** | 备份 / 冗余 / 无损重建（不丢 = 底线） |
| 自我 | 人格断裂（连续"我"断 → 言行漂移 / 自相矛盾） | **连贯** | 注入完整性 + 跨会话 / 换模型一致性校验 + 损坏检测恢复 |
| 超我 | 无良心（内化价值丢失 → 危险动作无约束） | **责任** | 危险动作确认（VEGA S4 已有）+ 记忆可审计 / 可回滚 + 价值约束 |

注：本我 / 自我护栏 = **系统属性**，落在 Hippocampus；超我护栏 = **行为属性**，横跨 VEGA（呈现体）+ 皮层，本项目只管"记忆可审计 / 可回滚"那一半。

## 5. 接口与主动性（框架已定 2026-10-14，用户拍板）

### 5.1 拓扑：引擎为枢纽

```
客户端层   VEGA / opencode / 其它 agent 客户端 / …      （零改动，接口=引擎）
   ⟷
皮层层     LLM 推理引擎（GB10，可换）
   ⟷
接线层     引擎侧薄 hook（serving 层）：读注入 / 写记录
   ⟷
器官层     Hippocampus（现役 GB10 102）：数据 + 嵌入 + 检索 + 轻门控（+ 巩固）
```

- **clients ⟷ 引擎**、**引擎 ⟷ 器官** 均**双向**；器官**不与 clients 直连**。
- **纠正**（用户 [手动] 原话）："我们设计思路错了，现在做的实际上 agent 客户端对话记录，接口应该对接 LLM 推理引擎。" 现行客户端侧记忆 API（各客户端插件各写各读）产出"agent 客户端对话记录"，与北极星（活得比会话 / 模型 / **客户端**长）冲突 ⇒ 记忆接口应对接**引擎**。
- **好处**：所有客户端零改动、记忆天然统一。

### 5.2 主动性：L3 为主 + L1 为辅

- **L3（主线）**：**器官主动 cue**——Hippocampus 按线索算相关度、主动喂记忆；皮层无感（表现为"自然想起"）。**守住"皮层可换"**（主动性不依赖皮层训练）。
- **L1（补充）**：留 `recall` 工具，供模型**刻意深搜**具体东西。
- 判定内核（相关度 / 门控）= **可训练的小模块，归器官**，不归皮层。

### 5.3 算力与硬件

- 器官（现役 GB10 102：aarch64 20 核 + GPU 嵌入容器）**算力足够 v1**：嵌入 + 检索 + 轻门控 ≈0.6s/轮（B1/B2 为 mini 时代口径 [手动]；102 recall `elapsed_ms=32`）。
- **红线：门控保持 embedding / 词法轻档，不用 LLM**（守轻档 / 低功耗取向；rerank 级 1–4s）。
- **设计原则：器官永远 CPU-可行**（对齐 PLAN §5 低功耗小盒子取向）。
- GPU / 神经门控 → **留 M2 或实测倒逼时再评估**；M2 做梦可**异步借 GB10 皮层**，未必需新机。
