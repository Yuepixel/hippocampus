## 1. 目标架构（已定）

```
客户端层  VEGA / opencode / 其它 agent 客户端 / …      （零改动，接口=网关）
   ⟷
接线层    自建网关（取代上游网关 upstream-gateway）：推理转发 + 记忆 hook
   ⟷
皮层层    LLM 推理引擎（GB10，可换）
   ⟷
器官层    Hippocampus（现役 GB10 102）：数据 + 嵌入 + 检索 + 轻门控（+ 巩固）
```

> **现役口径（2026-10-16 订正）**：器官机 = GB10 工机 **102**（`worker-node`）；原 Mac mini 2012 于 2026-10-15 退役留备用（D2-G5）。

- **网关 = 自建、作为 Hippocampus 的"接线层"组件**（取代上游网关；这样可控）。基座 = **借壳 / 先扫现成实现**（LiteLLM、one-api、Portkey…）后定 → **TBD，暂不展开**。
- 上游网关现提供（须复刻的最小集）：`POST /v1/chat/completions`(SSE) + `GET /v1/models`、Bearer 鉴权、模型别名→引擎路由、`reasoning_content`/思考控制透传；内部 `127.0.0.1:8889`、tailscale `443` 转发。
- **可丢**：管理台 / 引擎发现 / 下载 / 遥测 / 商店 / 配额 / 审计 / **priority-failover（会兜底到公网，必须去掉）**。
- **模块化接口（用户 2026-10-14 拍板 `[手动]`）**：**网关 / 海马体(Hippocampus) / 脑干** 三组件**一律设计成模块化接口**——契约稳定、可独立替换 / 演进、互不侵入（与"守皮层可换"同一逻辑）；脑干章程见 `docs/脑干设计-20261014.md` §9。

### 5.1 净结论（读正文后）

- **未被任何正文真正证明**的三件事：① 记忆可跨模型迁移（`2609.05339` 仅 48 合成历史 + <10B 模型；Kumiho 只换同厂答案模型）；② 巩固产出身份（DCPM 的 identity 是扁平属性表，非自模型）；③ 外置存储整体优于长上下文（DCPM 在 deepseek 列全负于长上下文基线）。
- **已被我们亲手证明**的一件事：**M0 连续性——记忆活过模型**。约 3 周内 GB10 皮层换代 ≥5 次（跨 Qwen3.6/3.8 ↔ GLM-5.3、跨 vLLM/SGLang/TabbyAPI/TensorFold、跨量化），记忆池（mem0 `user_id=demo` + git-memory）与 `agent_id` 身份不变。**这是论文们尚缺的实地证据。**
- **稳健的原因（设计踩对）**：现役是 `infer=false` **原文存储 + 向量索引**，正落在 `2609.05339` 认为稳健的"保留原始历史"一端；**尚未做激进压缩 ⇒ 避开了"压缩与写它的模型强耦合"的坑**（NOTES 不对称漂移 +9.91/−13.28pp）。

### 5.4 来源可信分级（用户方案，2026-10-14）= §5.2 的解

> 用户提出：**"眼见为实，事实是第一权威；网上消息有真有假，核实不了的不能全信；给信息分级：自己核实的最高、网上的半信半疑、风闻的存疑需核实。"**
> 完整设计见 `docs\来源可信分级-20261014.md`。这是 §5.2 红线 2–5 的**具体落法**。

| 级 | 来源 | 可信 | 单独承重 |
|---|---|---|---|
| **A 亲验** | agent 自己实测、可复现 | 最高 | ✅ |
| **B 直录** | 系统确定性记录 / 主人明示 | 高 | ✅ |
| **C 引证** | 网络/文档且**有出处** | 半信半疑 | ⚠️ 需 ≥2 来源 |
| **D 风闻** | 无出处转述/听说 | 存疑 | ❌ 须先核实 |

**三条机制（缺一不可）**：①**写时按"获取通道"打级**（权威是获取行为的属性，非文本属性）；②存储**按原措辞重构**（禁把 C/D 升级成 A/B 的语气）；③**读时门控**（高风险动作仅 A/B 单独承重，C/D 需 ≥2 来源）。**升级路径** D/C--核实-->A 记事件、留旧值。**约束**：B3 摘要继承来源最高级，**摘要本身不得高于来源**。
