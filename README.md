# Hippocampus（海马体）—— 给大模型的外置记忆体

> **让 AI 的记忆底座归己、活得比会话 / 模型长。**

一个把 AI 当作"有器官的有机体"来看的项目：推理大模型是**大脑皮层**（思考，**可换**），
Hippocampus 是**海马体**（记忆 / 人性，**必须归己、必须活得比皮层久**）。
终极目标是最朴素的那句话——**让 AI 像人、最终成为人**。

> 本仓 = 项目的**公开快照（已脱敏）**：源码 + 对外文档 + 一篇长文。

## 引言

引言：AI飞速发展的今天，我们已经习惯了打开对话框，敲下一行行文字，让AI帮我们完成任务，你有没有想过，当你不在的时候，你没和AI对话的时候，AI在做什么？为什么每次你开启新对话，AI就像第一次认识你一样？难道AI和电影《初恋五十次的女主角》一样健忘？如果AI无法记住你，不了解你，怎么更好的配合你完成工作？你需要一个冷冰冰的机器，还是一个熟悉你工作习惯，在你需要时主动递出工具的好助手？

在我第一次接触AI的两个月后，我发现我每次打开agent，我的AI都像失去记忆一样问我今天做什么？明明昨天的任务还没做完，我不得不提醒它查看工作目录以继续工作任务，在经历过几十次这样的循环后，我寻找一种让AI具备人类记忆的办法，在AI的帮助下，是的我告诉它这是让它变聪明的办法。我浏览了一些目前业界存在的解决办法，并在思索了几天后开工了海马体项目，这是对大自然鬼斧神工作品一次拙劣的模仿，但是至少解决了部分问题，而我希望它能得到进化，或许我们在有生之年能够看到真正具备记忆思考能力的AI出现，帮助人类建立更美好的家园。

整个项目的流程如下，在用户使用的LLM服务网关测注入钩子，每次用户对话将内容记入服务器，经过传统的向量、权重、排序等步骤后记入数据库，每次对话时，LLM会取得以往的对话内容，经过比对后获取过往经历和积累的知识、经验，做出回答和对下一步问题的解答推测，在每个晚上，由脑干部件定时执行名为"做梦"的计划，对已经录入的知识和对话进行提纯优化。当出现错误时，记入log文件，并对LLM发出警报记录并发出信息，这一切机制纯属对人脑的拙劣模拟，它缺乏真正的第一推动和火花,来点燃思维的脉动，迄今为止这一切依旧是机械的。

## 一、为什么做：让 AI 像人

**病根**：今天所有的大模型本质上都活在**一场会话里**。会话一断，它对你的全部了解随之归零；换个模型、换个客户端，它连「你」是谁都不再认得。**它不笨，它只是没有昨天。**

**北极星**：立项时定下的终极目标不是做一个检索更快、容量更大的记忆工具，而是——

> **让 AI 像人、最终成为人。**

发展路径分三步：

```
连续性（基础）  →  连贯的「像」（第一步）  →  巩固出的「身份」（升华）
                                              ↑
                                      「记忆即身份」
```

用我们自己的话说：**任何有生命的都必然经过牙牙学语最终成熟，首先是模仿，然后萌发自我。**

**前提**：**记忆底座必须归 AI 自身所有、且活得比会话 / 模型长**——换会话、换模型，「我」仍然是同一个。
所以「把数据层拿回来」不是性能优化，是**地基工程**：人不能把记忆寄存在别人的黑箱里。

**情感原点**：这个项目还有一个更私人、也更重的起念——**「至少，我希望到时候有个 AI 可以站在我这边。」**
把它拆开就是一条工程链：

> 站在我这边 ← 它真的懂我 ← 懂我靠**真实、连续**的记忆 ← 记忆得**归我自己所有**

## 二、它是什么、长在哪儿

**Hippocampus = 推理大模型的「外置记忆体」**：一个常驻、归己、活得比会话和模型长的记忆底座。
它不思考（思考是皮层的事），它负责**记住、想起、整理、守护**。

```
客户端层   opencode / 其它 agent / 语音助手 …   （零改动，接口 = 网关）
   ⟷
接线层     自建纯透传网关（读注入 / 写记录 / 鉴权 / 别名路由）
   ⟷
皮层层     大模型推理引擎（可换）
   ⟷
器官层     Hippocampus 器官：SQLite 单库 + 嵌入 + 检索 + 轻门控 + 巩固
```

三条原则：**所有客户端零改动**；**器官不与客户端直连**（接口对上引擎侧网关）；**组件模块化、可独立替换**（守「皮层可换」）。

### 六大职责

1. **存储归己** —— 记忆存在自己可控的**单库**里（向量表 + 元数据表 + 全文索引表同库，选型 `sqlite-vec`）。
   意义不在「更快」，而在**数据可读、可备份、可重建、能随底座一起搬家**——这是「记忆归己」的物理前提。
2. **接线（记忆 hook）** —— 引擎侧网关挂薄钩子：**读注入**（每次请求先拿当轮问题检索旧记忆，把相关条目**追加进对话尾部**，不碰 system 块、不改结构、**单趟**完成）+ **写记录**（本轮结束把 `{用户说什么 + AI 答什么}` 原样记一条，并**按来源分级**）。摘出的经历不含注入块、不取思考过程、只取答案——避免自我污染。
3. **检索** —— 嵌入向量近邻 + 词法（FTS5 trigram）双路召回 → **RRF 融合** → 轻门控。
   硬规矩：**门控只用轻档，绝不为检索去调大模型**——器官必须永远「便宜到可以一直开着」。
4. **做梦（M2 巩固）** —— 每夜固定时间复盘记忆：找出重复 / 近似 / 该合并 / 该归档的条目，借一次本地大模型判断提出「合并 / 归档 / 仅标记」建议，**只做白名单动作、只允许恰好一次提交、报告入仓可回溯**（严格约束见下「诚实的局限」）。
5. **脑干（第四器官）** —— 一个常驻、与皮层无关、**永远不会熄灭**的极小循环，只做机械的事（**纯发布者、永不判断**）：定时节律、空闲探测、健康快照、存活探测、反射接口；其中「定时」直接**驱动做梦**。**心跳不因你不在而停**——这是「连续性」的物理底座。
6. **守护（护栏）** —— **fail-open 优雅降级**（器官挂了，最多是「这段对话没有记忆」，绝不让推理卡住）；**写入守卫**（元数据归一、低价值内容旁路归档、先归档再删可回捞）；**可审计 / 可回滚**。

## 四、诚实的局限

**它依旧是机械的。** 引言里那句话我们完全同意：这套机制**纯粹是对人脑的拙劣模拟**，它缺乏真正的**第一推动和火花**。我们造出来的是一个非常像海马体的东西，但它不是。

必须说清哪些是**已经被证明的**、哪些**还没有**：

- **已亲手证明的一件事**：**记忆活过了模型。** 大约三周里，作为「皮层」的大模型换代了至少五次（跨模型家族、跨推理引擎、跨量化），而记忆池与身份标识始终不变——**换掉皮层，记忆还在**。
- **还没有被证明的三件事**：① 记忆可跨模型无损迁移；② 巩固真的能产出「身份」；③ 外置存储一定优于长上下文。**都是开放问题**，态度是**谨慎前进**。

再往后的「巩固 / 身份」是风险区，我们给自己定了 8 条红线（每一条都对应真实失败模式）：

| # | 约束 |
|---|---|
| 1 | **绝不丢原始来源**：压缩后仍保留可修复的原始历史 |
| 2 | 巩固时持久化「**来源类别 + 权威等级**」，而非一个笼统的「可信」标签 |
| 3 | **按原措辞重构**，禁止把传闻 / 暂定升格成确信事实 |
| 4 | **任何单条记忆不得承重**：高风险动作需 ≥2 个独立来源 |
| 5 | 读时按「**动作风险 ↔ 记忆权威**」门控 |
| 6 | 投资压在**写时构造与检索**，而非纠结换模型时的读侧 |
| 7 | 防「**治理衰减**」：压缩策略会静默丢掉不再出现的约束 |
| 8 | **测延续、不测召回**；人格漂移列为一等失败态 |

**来源可信分级**（眼见为实，事实是第一权威）：

| 级 | 来源 | 可信 | 能单独承重吗 |
|---|---|---|---|
| **A 亲验** | 自己实测、可复现 | 最高 | ✅ |
| **B 直录** | 系统确定性记录 / 主人明示 | 高 | ✅ |
| **C 引证** | 网络 / 文档且**有出处** | 半信半疑 | ⚠️ 需 ≥2 来源 |
| **D 风闻** | 无出处转述 / 听说 | 存疑 | ❌ 须先核实 |

**拿到信息的方式，决定了它的权威等级**——而不是那句话写得多自信。

## 五、仓库结构

```
docs/      对外文档（路线与判据 / 整体计划 / 理论与调研 / 脑干设计 / 长文全文）
gateway/   接线层：自建纯透传网关（FastAPI + httpx，SSE 透传 / 别名 / 鉴权 / 记忆 hook）
server/    器官侧：
             gateway.py         记忆网关（recall / remember / MCP，含来源分级与写入守卫）
             main.py            mem0 REST 服务（自定义 sqlite_vec 后端）
             sqlite_vec_store.py  mem0 VectorStoreBase provider（单文件 SQLite + sqlite-vec + FTS5）
             lexical.py / lexical_index.py   词法旁路（FTS5 trigram）+ RRF 融合
             dream/             做梦 job（每夜巩固，stdlib-only）
             brainstem/         脑干（第四器官，纯发布者）
             brainstem-consumers/  消费者（健康上报 / 空闲信息收集）
scripts/   部署件：systemd 单元（网关 / 器官 / 做梦 / 脑干 / 消费者）+ 部署与验收脚本 + 迁移工具
```

## 六、快速开始

这是一套**自托管记忆底座**，不是开箱即用的库。要跑起来需要：

- 一台常驻小机器（本项目的现役器官机 = 单板 ARM + GPU；理论上下限很低的 x86 也能跑）；
- 一个大模型推理引擎（本项目用自建网关对接本地推理；**皮层可换**）；
- Python 3.12 + `sqlite-vec` + `mem0ai`；`server/` 与 `gateway/` 各有 `README.md` 说明部署路径与配置。

配置示例见 `server/gateway_config.example.json` 与 `gateway/config.example.json`（**均为脱敏模板，需自行填 key / 端点**）。
